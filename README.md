# NutriDay

O **NutriDay** é um projeto acadêmico desenvolvido durante um curso de técnico de informática e sistemas para internet.
O objetivo é explorar os conceitos de desenvolvimento de aplicativos mobile, design de interfaces e experiência do usuário (UI/UX).

A proposta do aplicativo é oferecer uma experiência simples e intuitiva voltada à alimentação e ao acompanhamento dos hábitos alimentares.

## Objetivos do projeto

- Praticar conceitos de desenvolvimento mobile.
- Explorar princípios de UI/UX e design de interfaces.
- Definir uma identidade visual própria, incluindo logotipo e paleta de cores.
- Desenvolver habilidades técnicas por meio de um projeto prático.

## Tecnologias

- Kotlin
- Android Studio
